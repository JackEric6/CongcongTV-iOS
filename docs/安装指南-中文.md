# 丛丛影视 iOS 安装指南（Windows 用户）

> 适用于没有 Mac 电脑的 iPhone 用户。整个流程不需要 macOS，只需要一台 **Windows 电脑** + 一条 **Lightning/USB-C 数据线** + 一个 **Apple ID**。
>
> 本项目已在 GitHub Actions（macOS 云构建机）上自动编译出安装包（.ipa），
> 你只需要**下载安装包 + 用下面的任意一种方式装到 iPhone** 即可。

---

## 0. 先下载安装包（.ipa）

官方构建地址（GitHub）：

- **构建产物页面**：<https://github.com/JackEric6/CongcongTV-iOS/actions>
- 点击最新一次成功（绿勾 ✅）的 **“Build iOS App (IPA)”** 运行记录。
- 页面底部的 **Artifacts** 区 → 下载 **`CongcongTV-ipa`** 压缩包。
- 解压得到 **`CongcongTV.ipa`**（约几十 MB）。

> 提示：开启 Actions 的「允许访问公共制品」后无需登录 GitHub 也能下载；
> 未登录则先登录你的 GitHub 账号。

## 方案 A（推荐给非开发者）：AltStore + AltServer（Windows）—— 免费 Apple ID 即可

原理：AltServer 在你 Windows 电脑上常驻，用一个免费 Apple ID 给 AltStore 和
你安装的 App 签名，手机连接同一 WiFi 时自动续签。

1. **Windows 上安装 AltServer**
   - 打开 <https://altstore.io> ，下载 **AltServer for Windows**。
   - 安装并运行。如果提示需要 **iCloud / iTunes**，请先装好
     [iCloud for Windows](https://support.apple.com/zh-cn/118205) 和
     [iTunes for Windows（64 位）](https://www.apple.com/itunes/)。

2. **iPhone 上装 AltStore**
   - iPhone 用数据线连电脑，或连电脑同一个 WiFi。
   - 状态栏 AltServer 图标 → **Install AltStore** → 选择你的 iPhone。
   - 输入你的 **Apple ID 和密码**（仅用于签名，可随时在 Apple 账户里撤销应用专用密码）。
   - AltStore 图标出现后，在 iPhone **设置 → 通用 → VPN 与设备管理** 中信任该开发者描述文件。

3. **安装丛丛影视**
   - 把 `CongcongTV.ipa` 通过 **AltStore（Files）** 传进 iPhone：
     电脑端把 `.ipa` 拖进 iPhone 的“文件”→“我的 iPhone”→“AltStore” 文件夹，
     然后在 iPhone 的 AltStore 里点左上角 **+** 选择它；或
     用数据线 + AltServer 的 **"Install .ipa"** 选项直接装。
   - AltStore 会用你的 Apple ID 自动签名并安装。

4. **7 天续签（重要）**
   - 免费 Apple ID 签名的 App **7 天后过期**，打不开时到 AltStore 里点 App 的
     **Refresh All**（需电脑 AltServer 在线 + 手机同 WiFi）即可续签，日常使用基本无感。

> **常见坑**
> - 免费 Apple ID 同时最多侧载 **3 个** App，保持 AltStore 只装需要的。
> - 首次运行若被系统拦截：设置 → 通用 → VPN 与设备管理 → 信任。
> - 若报 “无法验证 App”：删除后重新通过 AltStore 安装即可。

## 方案 B：SideStore（全无线，免费）

AltStore 的无线版，手机端即可完成签名，不依赖每次连电脑：

1. 用 **AltStore + 免费 Apple ID** 先把 SideStore 装上（只此一次需要电脑）。
2. 打开 SideStore，用同一 Apple ID 登录；
3. 在 SideStore 里 **+** 导入 `CongcongTV.ipa` 安装。
4. 同理，免费 Apple ID 需 **7 天续签**（SideStore 在有网时自动/手动刷新）。

官网：<https://sidestore.io>

---

## 方案 C：TrollStore（永久签名，不折腾，但有系统版本限制）

如果你的 iPhone 支持（**iOS 14.0 – iOS 17.0** 的大部分机型），用 TrollStore 是最省心的：

- 永久签名，**永不过期**，无需电脑，无需 Apple ID。
- 支持导入**未签名/adhoc 签名**的 IPA，正适合本项目产出的安装包。

步骤：在支持列表内用
[TrollStore 安装教程](https://ios.cfw.guide/zh_CN/) 装好 TrollStore → 把
`CongcongTV.ipa` 通过 AirDrop / 文件 App 传到 iPhone → 用 TrollStore 打开并“安装”。

> TrollStore 不支持 iOS 17.0 以上 → 这类新系统请看方案 A/B 或 D。

---

## 方案 D：签名服务（不想每 7 天折腾）

网上有商业签名服务（各种“证书/签名平台”，淘宝/Telegram 等渠道很多），
只需把 `.ipa` 上传，付少量费用，由服务方用企业/开发者证书签名，**一般 1 年有效**。
注意这类平台鱼龙混杂，请自选信任的渠道，自行承担风险。

---

## 方案 E：Apple Developer 账号（$99/年，一劳永逸）

- 注册 Apple Developer Program（每年 **US$99**）。
- 用 Xcode Cloud / GitHub Actions 里配置开发者签名后自动构建，签名 **1 年有效**，
  可装到你自己所有设备，无 3 个 App 限制。
- 适合长期重度使用与后续给亲友分发（需把设备 UDID 加入配置描述文件）。

## 首次启动设置

1. 打开 **丛丛影视**，默认已内置原有配置（movie2，与你在 Android 上一致），
   直接可用，无需任何操作。
2. 若想换配置：首页/我的 → 设置 → 配置地址里填入
   `https://pse.is/9mr5uw` 或
   `https://ghproxy.net/https://raw.githubusercontent.com/JackEric6/movie/refs/heads/main/movie2`
   或任一张贴的 JSON。
3. 无法播放时：iPhone **设置 → 无线局域网 → 当前网络 → 配置 DNS**（如 223.5.5.5），
   或开启代理后重试，多数为网络环境问题。

## 重新签名/升级

- 升级：重新下载最新 `CongcongTV.ipa`，AltStore/TrollStore 里覆盖安装即可，历史记录保留。
- 重签名：到期后用 AltStore 的 Refresh（免费 Apple ID 需每 7 天一次）。

---

## 常见问题

- **打不开/闪退**：确认已“信任”开发者描述文件（设置→VPN 与设备管理）。
- **到期提示**：免费 Apple ID 签名有效期 7 天，用 AltStore/SideStore 的刷新功能续签。
- **播放卡顿**：多为片源服务器问题，与 App 无关，可换源或换网络。
